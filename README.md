# 이동형 얼음정수기 GUI — 동적 표현 · 날씨 연동

한우물 정수기 GUI(`260731_한우물 정수기 GUI/`)의 시각 언어를 이동형 얼음정수기로 확장한 제안입니다.
화면 규격 **1024 × 600 가로**, 기존 시안과 동일합니다.

## 산출물

| 파일 | 내용 |
|---|---|
| `prototype.html` | 실제로 구동되는 프로토타입. 배경 유체·파티클·추출 모션이 캡처가 아니라 실시간 렌더입니다. |
| `figma/01-tokens.js` | 피그마 디자인 토큰(컬러 변수) 생성 |
| `figma/02-master-screen.js` | 마스터 화면 1장(정수/맑음) 생성 |
| `figma/03-mode-variants.js` | 나머지 4개 모드 화면 생성 |
| `figma/04-weather-and-spec.js` | 날씨 6종 변형 + 모션 사양 보드 |

게시된 프로토타입: <https://claude.ai/code/artifact/9a80da46-6935-4eed-bd8d-210d2911a29e>

## 설계 요약

**화면 5종** — 추출 / 상세 설정 / 즐겨찾기 / 관리 알림 / 절전 대기.
추출 화면 하나에 모든 정보를 밀어 넣지 않았습니다. 필터 잔량·살균 이력 같은 관리 정보는
별도 화면으로 분리해 기존 시안의 여백감을 지켰고, 추출 화면에는 모드·용량·날씨만 남겼습니다.
상세 설정은 모드에 따라 항목이 바뀝니다 — 온수는 온도 3단, 얼음은 형태 2종, 정수는 온도 항목 자체가 없습니다.

**추출 모드 5종** — 온수 / 정수 / 냉수 / 얼음 / 얼음물.
기존 시안의 4탭(온수·정수·냉수·즐겨찾기)에서 즐겨찾기를 상단 아이콘으로 내리고,
이동형 모델의 핵심 기능인 **얼음**과 **얼음물**을 하단 탭에 올렸습니다.
얼음 모드만 단위가 `ml`이 아닌 `개`라 추출량 밴드의 숫자 체계를 분리했습니다.
단위 표기(`ml` / `개`)는 기존 시안 규칙대로 **선택된 항목에만** 붙습니다.

**날씨 연동 6종** — 맑음 / 폭염 / 흐림 / 비 / 눈 / 한파.
기상청 단기예보의 하늘상태·기온·특보를 6개 상태로 정규화하고,
각 상태가 배경 틴트 · 추천 문구 · 기본 프리셋을 동시에 결정합니다.
추천은 강제 전환이 아니라 `적용` 1회 탭으로 반영되는 제안 형태입니다.

**동적 표현** — 배경은 CSS가 아닌 Canvas 유체 렌더입니다.
파형 진폭이 추출 상태에 실시간 반응해야 해서(추출 중 1.0 → 2.6배) 정적 애니메이션으로는 구현되지 않습니다.
전체 모션 토큰(지속시간·이징·루프·트리거)은 프로토타입 하단 사양표와 `04` 스크립트에 값으로 고정돼 있습니다.

## 피그마 이관 절차

대상 파일: `한우물 이동형 얼음정수기 GUI_동적표현+날씨`
`https://www.figma.com/design/HEjWMZVZ0OBZKyylUZkisI` (file key: `HEjWMZVZ0OBZKyylUZkisI`)

> **선행 조건 — 플랜 업그레이드가 필요합니다.**
> Figma MCP 서버는 Starter 플랜에서 **월 6회** 호출만 허용합니다. 현재 계정의 3개 팀이 모두 starter라
> 팀을 바꿔도 한도는 동일하며, 이미 소진된 상태입니다. Professional(Full 시트) 이상이면 일 200회입니다.

업그레이드 후 `01 → 02 → 03 → 04` 순서로 `use_figma` 에 한 개씩 붙여넣어 실행합니다.
각 스크립트는 생성한 노드 id를 반환하며, `03`과 `04`는 앞 단계가 반환한 id를 상단 상수에 넣어야 합니다.

```
01-tokens.js            → 변수 컬렉션 "GUI Tokens"
02-master-screen.js     → ids.root 를 받아 적어 둘 것
03-mode-variants.js     → MASTER_ID 에 위 ids.root 입력
04-weather-and-spec.js  → SOURCE_ID 에 03이 반환한 "얼음물" 프레임 id 입력
```

### 스크립트에 관한 주의

이 4개 스크립트는 **피그마에서 아직 실행해 본 적이 없습니다** — MCP 호출 한도가 소진돼 검증 자체가 불가능했습니다.
Figma Plugin API 규칙(색상 0–1 범위, 폰트 선로드, `appendChild` 이후 `layoutSizing` 설정, 노드 id 반환)에 맞춰
작성했지만 첫 실행에서 수정이 필요할 수 있습니다. 실패하더라도 스크립트는 원자적이라 파일이 오염되지 않습니다.

폰트는 하드코딩하지 않고 실행 시점에 `listAvailableFontsAsync()` 로 한글 지원 패밀리를
Pretendard → Noto Sans KR → Apple SD Gothic Neo → 맑은 고딕 순으로 탐색합니다.

상태바 시스템 아이콘과 탭바 아이콘은 스크립트에서 문자 자리표시자로 들어갑니다.
프로토타입(`prototype.html`)에 5종 탭 아이콘과 6종 날씨 아이콘이 인라인 SVG로 들어 있으니,
피그마에서는 해당 SVG를 붙여넣어 교체하는 편이 빠릅니다.
